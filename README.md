# 🍾 Atelier Coca-Cola — Cinematic Scroll Animation

> **Edition 2025 • Haute Refreshment & Archive Research**  
> *Crafted & Designed by **Prince.a.ron***

An award-winning editorial luxury web experience featuring a buttery-smooth **300-frame scroll-driven canvas animation** (can pop, liquid cascade, slow-motion ice splash, and frosted serve) coupled with an ultra-clean **transparent liquid glass floating navbar** and high-fashion archival storytelling.

---

## ✨ Features
- **300 HD Frame Sequence**: High-performance HTML5 Canvas 2D rendering with Retina DPI support.
- **Pinned Fluid Pour Control**: Screen stays locked during the entire 300-frame sequence with realistic liquid inertia easing (`0.055`), then seamlessly scrolls into the editorial website.
- **Liquid Glass Floating Navbar**: Minimalist floating capsule with 28px blur, specular top highlight, crimson caustic bottom reflection, and automated scroll-spy section tracking.
- **Curated Editorial Sections**:
  - `01 / ESSENCE` — Brand Story & Formula Discipline
  - `02 / SENSORY ARCHITECTURE` — Thermal Thresholds (4°C), Micro-Bubbles & Hobble-Skirt Glass
  - `03 / EDITION PORTFOLIO` — Original Taste, Zero Sugar & Reserve Cacao & Cherry
  - `04 / ATELIER CAMPAIGN 2025` — Architectural Tokyo Penthouse Lifestyle Frame
  - `05 / THE ARCHIVE VAULT` — Private Allocation Casework & Concierge Request
- **Vercel Edge Ready**: Pre-configured `vercel.json` with immutable 1-year CDN caching on all 300 frame assets for instantaneous global loading.

## 🚀 How to Push to GitHub

Run these commands in your terminal:

```bash
# 1. Initialize Git repository
git init

# 2. Add all files
git add .

# 3. Create initial commit
git commit -m "feat: Atelier Coca-Cola 300-frame scroll animation website by Prince.a.ron"

# 4. Set branch to main
git branch -M main

# 5. Link your GitHub repository (replace with your repo URL)
git remote add origin https://github.com/YOUR_USERNAME/YOUR_REPOSITORY_NAME.git

# 6. Push to GitHub
git push -u origin main
```

## ⚡ How to Deploy on Vercel

### Method 1: Via Vercel Web Dashboard (Recommended)
1. Go to [vercel.com](https://vercel.com) and log in.
2. Click **"Add New..."** → **"Project"**.
3. Select your GitHub repository.
4. Framework Preset: Leave as **Other** (Static Site).
5. Root Directory: `./` (default).
6. Click **Deploy**. Done! 🎉

### Method 2: Via Vercel CLI
```bash
npm install -g vercel
vercel
```
